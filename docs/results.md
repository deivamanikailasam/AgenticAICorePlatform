## What has not been measured

- **Quality on real models.** No run with `--provider gateway` against real models has been recorded, so there is no task-success rate, judge score, AUD per task or latency for any app on a real model. These are VERIFY-ON-MAC: `just eval-app <app> --provider gateway` on the owner's machine records them.
- **Judge agreement with people.** The judges' calibration needs human labels (`evals/labels/`), which haven't been given.
- **Multi-agent against single-agent.** Whether the research-report team beats one agent on the same tasks needs the real-model runs above.
