# Overlays pinned to the images of 91fd4b0

## What changed
dev, staging and prod now pin agent-api, agent-worker, mcp-gateway, a2a-gateway and ops to the
digests the images workflow pushed, signed and scanned for commit 91fd4b0. Until now they pinned
4ff80dc.

## Why
91fd4b0 fixes the start-up crash ("Event loop is closed") that left the dev application Degraded
in deploy-e2e. The fix only reaches a cluster through new images.

## How to check it
`just deploy-check` (0 problems). The images workflow run for 91fd4b0 lists the same digests;
deploy-e2e on this commit syncs dev with these images.

## Risks and follow-ups
Prod's overlay is a governance path: on main this bump needs the named approver.
