# Overlays pinned to the images of 9a999b8

## What changed
dev, staging and prod now pin agent-api, agent-worker, mcp-gateway, a2a-gateway and ops to the
digests the images workflow pushed, signed and scanned for commit 9a999b8. Until now they
pinned 91fd4b0.

## Why
9a999b8 fixes the a2a-gateway's start-up crash (a nested `asyncio.run`). That crash left the dev
application Degraded in deploy-e2e on 902589c, after the OpenBao fix of 91fd4b0 had made every
other pod healthy. These images also carry the agent SDK and the loading of a team's installed
tools (Step 39).

## How to check it
`just deploy-check` (0 problems). The images workflow run for 9a999b8 lists the same digests.
deploy-e2e on this commit syncs dev with these images.

## Risks and follow-ups
Prod's overlay is a governance path: on main this bump needs the named approver.
