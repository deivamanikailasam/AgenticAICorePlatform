# Overlays and the agent-project template pinned to the images of 1ba0391

## What changed
- dev, staging and prod now pin the five images that the images workflow pushed, signed and
  scanned for 1ba0391. Until now they pinned 9a999b8.
- `just template-data` regenerated the template from these pins:
  - `platform_ref` is now 1ba0391;
  - the template's overlays carry the same digests.

## Why
1ba0391 is the first commit whose images contain:
- the SDK's packaging fixes (policy data and config in the wheels);
- `agentctl deploy-check`;
- the self-contained base;
- the Dockerfile fix.

A project made with the template's defaults now gets an SDK that matches the images it deploys.
The images built for the commits between 320926a and 0476e7f couldn't include the policy data,
because the Dockerfile didn't copy it.

## How to check it
- `just deploy-check`: 0 problems.
- `just template-data-check`: up to date.
- The images workflow run for 1ba0391 lists the same digests.
- deploy-e2e and template-e2e run on this commit.

## Risks and follow-ups
Prod's overlay is a governance path: on main this bump needs the named approver.
