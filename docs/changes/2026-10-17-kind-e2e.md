# The platform on a real cluster: kind, Argo CD, KEDA (deploy-e2e)

## What changed
- `deploy/argocd/install` and `deploy/keda`: Argo CD v3.5.3 and KEDA 2.21.0 for the cluster.
  `just cluster-addons` downloads each release manifest and checks its SHA-256. Every image is
  pinned by digest; Argo CD's Redis comes from Docker Hub. Argo CD builds overlays with the load
  restrictor off.
- `just kind-e2e` (`scripts/kind_e2e.py`, CI workflow `deploy-e2e` on deployment changes and
  daily):
  - a kind cluster (Kubernetes 1.37, pinned node image) with Argo CD and KEDA;
  - every overlay and the Argo CD apps as a server-side dry run, so the API server, Pod Security
    `restricted` and KEDA's webhook judge each object;
  - the stand-in bridged in as the `rag-platform` namespace;
  - OpenBao's Kubernetes auth set up for the dev namespace's service accounts, with a dev KV
    mount;
  - the dev Application synced by Argo CD from the commit, with that commit's signed images;
  - a run of hello-workflow through agent-api from an admitted namespace;
  - a probe from a non-admitted namespace, which must fail.
  - It writes `evals/results/deploy/kind-e2e.json`.
- The bridged stand-in is reached through an e2e-only egress policy for its subnet. Its
  containers are endpoints, not pods, so the platform's namespace-selector rule can't match them.
  The shipped manifests are unchanged.

## Why
Step 38 deploys with Kustomize and Argo CD. Rendering and schema checks (deploy-check) do not
prove the API server admits the pods, that Argo CD syncs them, or that the services start and
serve inside a cluster with network policy enforced.

## How to check it
The `deploy-e2e` workflow run for this commit, and its `kind-e2e` artifact.

## Risks and follow-ups
- This build container cannot run kind (nested Docker: runc may not set `oom_score_adj`), so the
  check runs in CI only.
- Staging and prod are judged here by admission only (dry run). Their Temporal cluster, External
  Secrets and KEDA scaling on a live queue are verified on the real cluster (VERIFY-ON-MAC).
